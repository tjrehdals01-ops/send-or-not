# 보내도 돼?

메시지를 보내기 전, 상대와 목적에 맞게 문장을 다듬고 여러 말투를 비교할 수 있는 웹 서비스입니다.

## 주요 기능

- 상대방과 메시지 목적을 직접 입력
- 카카오톡, Instagram DM, 이메일 상황 선택
- 한국어·영어 문장 작성
- 원본·기본형·단호하게·정중하게 결과 비교
- 결과 복사 및 모바일 공유

## 실행 사이트

[보내도 돼? 바로가기](https://bonaedo-dwae.skku-boot5.chatgpt.site)

## 로컬 실행

Node.js 22.13.0 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 기술 스택

- Next.js
- TypeScript
- React
- CSS
